./run.sh

Privacidad por diseño

Tus tarjetas son tuyas.

SQLite local, backups JSON y exportación APKG funcionan offline. No requiere OpenAI, ChatGPT, Codex ni ninguna API cloud. La integración con modelos y navegador es opcional y viene desactivada.
